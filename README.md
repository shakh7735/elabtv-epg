# elabtv-epg

Гиды программы передач для **внешних** плейлистов ElabTV — провайдерских, без `tvg-id`.

Как это работает:

1. Приложение с внешним плейлистом и встроенным источником программы считает отпечаток списка
   названий каналов (SHA-256 отсортированных названий через `\n`, первые 16 hex-знаков) и качает
   `https://raw.githubusercontent.com/shakh7735/elabtv-epg/guides/<отпечаток>.xml.gz`.
2. Нет такого гида — кладёт названия в `lists/<отпечаток>.txt` (первая строка `# seen: ГГГГ-ММ-ДД`,
   дальше по названию на строку). Коммит запускает workflow **Guides**, через несколько минут гид
   готов. Адресов потоков и ключей провайдера в списке нет — только названия.
3. Все гиды пересобираются раз в 6 часов. Раз в неделю приложение обновляет `# seen:`; список,
   о котором не вспоминали 30 дней, удаляется вместе с гидом.

Подбор программы — `tools/build.py` (описание правил — в начале файла). Источники — `sources.json`.
Ошибся подбор — строка в `map.json`: `{"Название в плейлисте": ["epgone", "1234"]}`, со сдвигом
`["epgone", "1234", 2]`, `null` — оставить канал без программы. Рядом с каждым гидом в ветке
`guides` лежит `<отпечаток>.txt` — откуда какой канал взял программу.

Запись в `lists/` приложение делает fine-grained токеном, у которого есть только `Contents: write` на
этот репозиторий. Токен лежит в apk, поэтому здесь ничего, кроме гидов, не хранится: худшее, что
им можно сделать, — испортить гиды, которые и так пересобираются.

Собрать на своём компьютере: `python3 tools/build.py` (без зависимостей, Python 3.9+).
